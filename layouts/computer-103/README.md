# Layouts for 192.168.0.103

Copy this folder onto computer 3 and double-click a preset there. HDMI 1 (TV13) is the top monitor and HDMI 2 (TV18) is the monitor directly below it. Both are 1920×1080, landscape, 100% scale.

| File | What you should see |
|---|---|
| `Edge-Independent.bat` | One page on TV13 and one page on TV18 |
| `Edge-Full.bat` | One page covering both monitors |
| `Edge-Close.bat` | Closes these windows |

The pages open in the normal signed-in Edge profile at https://ccv2.mtllc.us/landing. Leave the command window open while a preset is on screen.
